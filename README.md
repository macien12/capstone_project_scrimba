# Personal Dashboard

A Scrimba capstone project that brings a nature photo, the current time, weather, Dogecoin prices, and an inspirational quote together on one dashboard.

## What I learned

- How to use `fetch` to request data from APIs and turn JSON responses into JavaScript objects.
- How to work with asynchronous JavaScript using `async` and `await`.
- How to handle failed requests with `try...catch`, check response status, and provide a fallback background image.
- How to update the page dynamically using the DOM, including setting text, HTML, and CSS styles from JavaScript.
- How to use the browser's Geolocation API to request a location and display local weather.
- How to display the current time and update it regularly with `setInterval`.
- How to build a dashboard layout with CSS Flexbox, viewport sizing, and a full-screen background image.
- How to use Vite to run a local development server and build a project.

## Getting started

Install the dependencies and start the development server:

```bash
npm install
npm start
```

Open the local URL shown in the terminal. Weather requires permission to access your location, and API-powered content depends on the services being available.

To create a production build, run `npm run build`.
